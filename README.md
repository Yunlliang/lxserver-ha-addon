# LXServer Home Assistant Add-on Repository

将 LXServer 封装为 Home Assistant OS 加载项，支持通过 HA 加载项商店安装和管理。

## 项目地址

- 原项目：https://github.com/XCQ0607/lxserver
- 加载项仓库：https://github.com/Yunlliang/lxserver-ha-addon
- Docker 镜像：`xcq0607/lxserver:latest`

## 安装方法

1. 打开 Home Assistant。
2. 进入 **设置 → 加载项 → 加载项商店**。
3. 点击右上角菜单，选择 **仓库**。
4. 添加仓库地址：

   `https://github.com/Yunlliang/lxserver-ha-addon`

5. 刷新加载项商店，找到 LXServer。
6. 安装并启动加载项。

## 访问地址

- LXServer：http://HA-IP:9527
- 管理后台：http://HA-IP:9527/admin

## 说明

本项目是第三方 Home Assistant 加载项封装，并非 LXServer 官方发布版本。
