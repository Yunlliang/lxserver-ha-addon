# LXServer

将 LXServer 音乐服务运行在 Home Assistant 中，可通过浏览器访问音乐网页和管理后台，并使用上游 LXServer 支持的数据同步功能。

本加载项是第三方封装，并非 LXServer 官方版本。具体功能及客户端兼容性请参考 [LXServer 原项目](https://github.com/XCQ0607/lxserver)。

## 快速使用

1. 安装加载项后，点击 **启动**，等待服务启动完成。
2. 在浏览器打开 `http://HA-IP:9527`，进入音乐网页。
3. 打开 `http://HA-IP:9527/admin`，进入管理后台，按照页面提示完成登录和设置。
4. 如需客户端数据同步，请参考原项目文档，按客户端支持的连接方式填写服务器地址和认证信息。

将 `HA-IP` 替换为 Home Assistant 主机的局域网 IP 地址，例如 `http://192.168.1.100:9527`。

## 常用说明

- 默认访问端口为 **9527**。如在加载项的网络设置中修改了主机端口，请使用修改后的端口访问。
- 本加载项通过独立端口访问，使用上面的地址在浏览器中打开。
- 如需随 Home Assistant 启动，可在加载项页面启用 **开机启动**。
- 网页中的音乐资源、音源设置及客户端功能由上游 LXServer 提供，以实际页面和上游文档为准。

## 无法访问时

1. 确认加载项状态为 **运行中**，并查看 **日志** 中是否有启动错误。
2. 确认访问设备能连接 Home Assistant 所在的局域网。
3. 核对主机 IP、端口以及是否存在端口冲突。
