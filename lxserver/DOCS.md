# LXServer 使用教程

## 启动与访问

1. 在 Home Assistant 的 **设置 → 加载项 → LXServer** 页面点击 **启动**。
2. 等待启动完成，在浏览器打开 `http://HA-IP:9527` 访问音乐网页。
3. 管理后台地址为 `http://HA-IP:9527/admin`，登录和配置请按照页面提示操作。

`HA-IP` 为 Home Assistant 主机的局域网 IP。例如，主机 IP 是 `192.168.1.100`，则网页地址为 `http://192.168.1.100:9527`。

如修改了加载项网络设置中的主机端口，请将地址中的 `9527` 替换为实际端口。

## 设置与同步

本加载项不提供额外的 YAML 配置选项。音乐网页和管理后台中的设置，以及客户端的数据同步连接方式，请参考 [LXServer 上游文档](https://github.com/XCQ0607/lxserver)，并以当前版本页面为准。认证信息请使用服务实际配置的值。

## 日常管理

用户列表、服务配置、歌单等数据保存在 Home Assistant 为加载项提供的持久化目录 `/data` 中，日志位于 `/data/logs`。重启、重新创建容器或更新加载项时会保留这些数据；请使用 Home Assistant 备份包含本加载项的数据。

旧版将数据写入容器内的 `/server/data`，可能在容器重新创建后丢失。升级前如旧用户仍可访问，请先使用上游支持的备份功能导出数据，升级后再恢复。已经丢失的数据需要从已有备份恢复；卸载加载项前也请先备份。

- **开机启动**：在加载项页面启用，随 Home Assistant 启动服务。
- **日志**：遇到启动失败、连接失败时，先查看加载项日志。
- **重启**：在加载项页面点击重启，然后重新打开网页。

## 常见问题

### 加载项运行中，但网页打不开

确认使用的是 Home Assistant 主机 IP，访问设备能连接该主机，且端口与加载项网络设置一致。检查是否有其他服务占用了同一主机端口，再查看加载项日志。

### 如何使用音乐功能或连接客户端？

音乐资源、音源配置、账号和客户端兼容性由上游 LXServer 决定。请查看网页提示及 [原项目文档](https://github.com/XCQ0607/lxserver)。

### 在哪里反馈问题？

加载项安装和封装问题可在 [加载项仓库](https://github.com/Yunlliang/lxserver-ha-addon/issues) 反馈；LXServer 自身功能问题请参考上游项目。反馈时请隐藏日志中的密码、令牌及其他认证信息。
